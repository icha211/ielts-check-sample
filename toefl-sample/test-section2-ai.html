❓ FAQ

Q: Where do I get an API key?
A: Visit console.anthropic.com, sign in, and generate an API key
Q: Is my API key secure?
A: Yes! The key is stored only in your browser's localStorage and never sent to any server except Anthropic's official API
Q: Why is my generation timing out?
A: Claude API sometimes takes 15-30 seconds for complex questions. Make sure your internet is stable and try again
Q: Can I edit explanations after generation?
A: Yes! The preview modal lets you see the HTML. You can copy and refine it before saving to your draft
Q: Does this work for all Section 2 questions?
A: It works best for Part A (Structure). For Parts B & C (Written Expression), the quality may vary

🔧 Troubleshooting

  • API key not configured: Click "Configure API Key" in the developer dashboard
  • Invalid API key format: Make sure your key starts with "sk-ant-"
  • API request timed out: Check your internet connection and retry
  • Failed to parse JSON: The AI response format was unexpected. Try rewording the question
  • No results showing: Open developer console (F12) and check for error messages
